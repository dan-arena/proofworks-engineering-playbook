# Longest Non-Repeating Substring (Sliding Window)

## Problem
Find the longest substring in a string that contains no repeating characters.

Examples:
- "abcabcbb" => "abc"
- "abcabcbbxyz" => "bxyz"

## Concepts
- Sliding window
- HashSet<char>
- Two-pointer technique
